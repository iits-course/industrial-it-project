# Интерактивный HTML-прототип «РемКонтур»

Кликабельный desktop-first прототип системы управления заявками на ремонт оборудования. Backend не используется: демонстрационные заявки, очередь офлайн-операций и состояние интерфейса хранятся в `localStorage` браузера.

## Запуск

Из корня репозитория:

```bash
cd prototype
python3 -m http.server 4173
```

Открыть <http://127.0.0.1:4173>. Прямое открытие `index.html` через `file://` не рекомендуется, потому что браузеры ограничивают загрузку JavaScript-модулей с локального диска.

## Сценарии

1. Роль «Сотрудник цеха»: создать заявку, проверить обязательные поля и предупреждение о дубле.
2. Роль «Диспетчер»: открыть новую заявку, изменить приоритет и назначить специалиста.
3. Роль «Инженер»: открыть назначенную заявку, начать работу, сохранить диагностику и завершить ремонт.
4. Роль «Диспетчер»: закрыть выполненную заявку; закрытие без результата блокируется.
5. Отключить соединение в боковой панели, создать заявку, перезагрузить страницу и восстановить соединение. Локальная операция должна синхронизироваться без дубля.
6. Включить состояния пустого списка, отсутствия специалистов и тестовой ошибки.
7. Кнопка «Сбросить демо-данные» возвращает исходный набор заявок и настроек.

## Автоматические проверки

Требуется Node.js 20+.

```bash
cd prototype
npm install
npm test
npm run test:spike
npm run test:browser
```

- `npm test` — модульные тесты локальной очереди и идемпотентного хранилища;
- `npm run test:spike` — 50 прогонов каждого из семи сценариев технического эксперимента;
- `npm run test:browser` — основные пользовательские пути в Chromium через Playwright.

## Ограничения

- Это HTML-прототип, а не промышленное приложение: нет backend, SSO, реальной многопользовательской работы и сетевого API.
- «Серверное» состояние моделируется отдельной областью `localStorage`; Spike проверяет алгоритм ещё и на файловом адаптере Node.js.
- Порог производительности NFR-03 и защита NFR-04 этим прототипом не подтверждаются.
- Требование занятия о Figma/Penpot остаётся на согласование: текущий макет следует перенести в выбранный инструмент или формально согласовать HTML-прототип как эквивалент для Practice 1.
